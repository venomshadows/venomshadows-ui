# Бэклог venomshadows-ui (следующая версия)

Собрано при переводе пяти сервисов на пакет (сентябрь 2026). Пункты, закрытые в 0.1.3, удалены.

- **bulk_bar и узкие экраны.** Бар прилеплен к низу, но в DOM стоит до таблицы: порядок Tab идёт после всех строк; на 360px бар занимает ~214 из 800px. Решить в пакете: перенос в DOM после таблицы или skip-ссылка, компактный ряд действий на узких экранах (rkn F-8, index F16).
- **Карточная шапка в server-режиме** без обёртки `fixed` уезжает при прокрутке страницы.
- **`.btn-link--danger`** — красная текстовая кнопка с hover; brand держит локальное правило.
- **`secret_field`** — условный placeholder: разный текст для «задан» / «не задан» (rkn).
- **`list.input` для навигации** — параметр для полей, которые делают GET-переход, а не фильтруют список (без `data-list-filter`). complaints сейчас вырезает атрибут через `|replace` (помечено «remove with venomshadows-ui v0.1.4»).
- **URL в list.js** — при записи обрезать пробелы в `q` и писать параметры в каноническом порядке (косметика).
